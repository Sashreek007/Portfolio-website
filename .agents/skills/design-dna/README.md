# design-dna — reference design systems

Reverse-engineered brand design specs from
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md),
curated down to the six systems closest to this portfolio's identity
(warm dark canvas · Geist Mono + Syne · editorial · dev-tool adjacent).

Consult these when making design decisions for this site:

| File | Why it's here |
|---|---|
| `warp.md` | Closest sibling: warm dark canvas ("pure black breaks the brand"), mono + sans pairing, terminal imagery as the only decoration. |
| `linear.app.md` | Surface-ladder elevation without shadows, accent scarcity (one chromatic color, four uses), negative display tracking + positive eyebrow tracking. |
| `vercel.md` | Geist family voice: mono for eyebrows/labels only, stacked subtle shadows (never one heavy drop), sentence-case period-terminated headlines. |
| `raycast.md` | Dark-only product-as-marketing, keycap `<kbd>` glyph pattern, hairline borders carry every edge, accents confined to illustrations. |
| `wired.md` | Editorial/magazine DNA for the blog: hairline story rows, three faces / three roles, typography carries the identity. |
| `stripe.md` | `tnum` on every numeric cell, one filled CTA per band, tight transactional pills. |

House rules these validate (do not regress):
- Warm near-black `#0E0E0C` canvas — never pure `#000`.
- One filled (violet) CTA per view; everything else glass/ghost.
- Amber = numerals/metrics only. Green = status only.
- Elevation via surface ladder + hairlines, not heavy drop shadows.
- Mono for labels/eyebrows/code; Syne for narrative headlines.
